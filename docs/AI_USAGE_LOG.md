## Review record

- Parallel AI tasks used shared contracts so lexer/parser/semantics, IR/optimization and target generation could be tested independently.
- Reference outputs were checked against separately written arithmetic/Boolean equations; no human review is claimed.
- Corrections included a test syntax typo, TypeScript narrowing, expected source-column arithmetic, patched test dependencies, copy scheduling, reserved SVG routing tracks, legal prototype-like signal names in UI state, source-selection endpoints, keyboard interactions and the export dropdown's stacking order.
- The compiler contains no API call, React import, DOM dependency, parser generator or graph-layout library. AI HTTP simulations are confined to tests of the optional external service boundary.
- Browser QA and source review were used together. The code is readable source, not an opaque generated bundle; students can follow each phase in its own module.
